Лабораторная работа №2, вариант 16
Автор: Каролина Капитонова, группа 932420.
Тема: «Предприниматель и стартапер». Страница «О себе» из ЛР №1, оформленная с помощью внешнего CSS-файла.

Цель: Научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

Реализовано:
- Три способа подключения CSS: внешний файл style.css, внутренний блок <style> (правило для ссылок в подвале), inline-стиль cursor: pointer у кнопки отправки формы.
- CSS-переменные в :root: основной цвет - оранжевый, акцент - белый, плюс вспомогательные оттенки и два шрифта.
- Позиционирование: static у заголовка «Проекты», relative у секции «Навыки», absolute у бейджа «Главное» в правом верхнем углу этой секции.
- Состояния элементов: :hover, :focus, :active у кнопки; :focus у полей формы; :visited, :hover, :active, :focus у всех ссылок, включая ссылки вне подвала.
- Кнопка-приманка: анимированный градиент, сдвигающийся при наведении; белая обводка и тень при фокусе; уменьшение сдвига при нажатии.
- Контрастность текста не менее 4.5:1.
